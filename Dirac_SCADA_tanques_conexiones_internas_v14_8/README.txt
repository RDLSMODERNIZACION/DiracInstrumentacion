DIRAC SCADA - TANQUES CON CONEXIONES INTERNAS V14.8

Objetivo:
Que las conexiones de los tanques den la sensación de salir desde adentro.

Antes:
- laterales aprox. x ±150
- visualmente quedaban afuera del cuerpo

Ahora:
- laterales x ±118
- tres alturas por lado
- puntos superiores/inferiores también quedan levemente dentro
- la cañería entra visualmente dentro del tanque

No modifica:
- pozos
- bombas
- Pump Pipe Taps
- Supabase

Aplicar desde la raíz:
.\Dirac_SCADA_tanques_conexiones_internas_v14_8\APLICAR_TANQUES_CONEXIONES_INTERNAS_V14_8.ps1

Después:
cd FrontEnd\App_2
npm run dev
