DIRAC APP 1 - TANQUES PROMEDIO SIMPLE V18.0

Objetivo:
simplificar el gráfico principal de nivel de tanques.

ANTES:
- banda mínimo/máximo
- mínimo real
- máximo real
- promedio operativo
- puntos y etiquetas superpuestas

AHORA:
- una sola línea: NIVEL PROMEDIO
- una sola métrica grande: PROMEDIO DEL PERÍODO
- tooltip simple con hora + promedio
- eje 0/25/50/75/100 %
- sin banda sombreada
- sin mínimo/máximo
- sin etiquetas superpuestas

Aplicar desde la raíz:
.\Dirac_App1_tanques_promedio_simple_v18_0\APLICAR_APP1_PROMEDIO_TANQUES_V18_0.ps1

Después:
cd FrontEnd\App_1
npm run dev
